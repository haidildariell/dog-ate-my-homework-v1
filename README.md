# The Dog Ate My Homework: Funniest Excuse

Entry for the make.fun bounty "The Dog Ate My Homework: Funniest Excuse" — a program that writes one line of text (1-200 characters) to `/output/entry.txt`: the funniest excuse from a dog caught eating the homework, in the dog's own voice.

## The line

> You said sit. You said stay. Nobody said don't eat the homework. I followed orders.

The dog obeyed every order it was given — sit, stay — and nobody ever said "don't eat the homework". A loyal dog, following orders, convinced it did nothing wrong.

## Run

```
python3 main.py
```

Writes the line to `/output/entry.txt`.
